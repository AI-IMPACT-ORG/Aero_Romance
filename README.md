## Romance (Aero) — novel + structured design graphs

This repository contains working materials for the romance novel **“Ærø's Healing Heart”**:

- **Manuscript text**: Markdown chapter drafts
- **Story architecture**: JSON-LD graphs for characters, locations, plot, style, and related ontology/agent graphs
- **Notes/Explain docs**: supporting structure and guidance for the story

## Repo layout

- `Aero/Chapters/`: main chapter drafts (`chapter_*.md`)
- `Aero/Design/`: structured JSON-LD design data (`*.jsonld`) and some narrative structure notes (`*.md`)
- `Aero/EXPLAIN/`: explanatory docs (`*.md`)
- `Aero/ALT/`: alternate designs/drafts (chapters + JSON-LD graphs)
- `Aero/Latex/`: LaTeX sources and build artifacts (PDF outputs may be present)
- `Scripts/`: small utility scripts (e.g., chapter conversion)
- `RomanceNovelArchitecture.dsl`: a graph-based romance novel architecture DSL
